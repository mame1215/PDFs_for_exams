# 考査対策用PDF

定期考査対策に向けた、漢字対策や唱える漢文･改などのPDFをここで公開していきます。ダウンロードは自由です。

## ファイルのダウンロード方法<br>

▽ダウンロードするファイルの考査のフォルダに入ります。<br>

<img width="1920" height="1080" alt="スクリーンショット (58)" src="https://github.com/user-attachments/assets/60f9626a-9559-4ea8-8885-782c09042f08" /><br>

▽ダウンロードするファイルを選択します。それぞれのファイルは、選択するとGitHub内でプレビューが閲覧可能です。<br>

<img width="1920" height="1080" alt="スクリーンショット (59)" src="https://github.com/user-attachments/assets/4f438d5d-6690-450f-a278-e100c771bfd4" /><br>

▽右上の **Download raw file** からダウンロードを開始します。<br>
